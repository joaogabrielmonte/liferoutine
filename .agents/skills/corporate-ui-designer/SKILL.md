# Corporate Enterprise UI Design Guidelines

When building or styling Web Admin and Dashboard interfaces in this codebase, adhere strictly to Senior Corporate Enterprise UI/UX standards:

## 1. Color Palette (Corporate Enterprise Palette)
- **Primary / Brand**: `#2563EB` (Royal Blue), `#1D4ED8` (Deep Blue hover)
- **Background (Light)**: `#F8FAFC` (Slate 50), `#FFFFFF` (Pure White cards)
- **Background (Dark)**: `#0F172A` (Slate 900), `#1E293B` (Slate 800 cards)
- **Borders & Dividers**: `#E2E8F0` (Slate 200 light), `#334155` (Slate 700 dark)
- **Text Primary**: `#0F172A` (Dark), `#F8FAFC` (Light)
- **Text Secondary**: `#64748B` (Slate 500)
- **Status Emerald**: `#059669` (Active / Success)
- **Status Danger**: `#DC2626` (Blocked / Danger)
- **Status Amber**: `#D97706` (Warning)

## 2. Typography & Layout Structure
- High contrast, clean geometric typography with subtle uppercase labels (`letterSpacing: 0.5`).
- Crisp metric cards with key numeric indicators, percentage changes, and status trend pills.
- Structured Enterprise Data Tables with crisp border lines, header backgrounds (`#F1F5F9` / `#1E293B`), zebra row striping, avatar initials, and inline action buttons.
- Sidebar Navigation: Collapsible or clean fixed left sidebar with section headers (`VISÃO GERAL`, `ADMINISTRAÇÃO`, `CONFIGURAÇÕES`).
