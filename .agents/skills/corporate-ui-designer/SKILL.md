# Minimalist Enterprise UI Design System (Shadcn / Vercel / Linear Style)

Adhere strictly to modern minimalist design principles:

## 1. Color Palette (Neutral Achromatic Base)
- **Background (Dark)**: `#09090B` (Zinc 950), `#18181B` (Zinc 900 surface), `#27272A` (Zinc 800 hover/active)
- **Background (Light)**: `#FFFFFF` (Pure White), `#FAFAFA` (Zinc 50 surface), `#F4F4F5` (Zinc 100 hover)
- **Borders**: `#27272A` (Dark), `#E4E4E7` (Light) - Hairline subtle borders only.
- **Text Primary**: `#FAFAFA` (Dark mode), `#09090B` (Light mode)
- **Text Secondary**: `#A1A1AA` (Zinc 400), `#71717A` (Zinc 500)
- **Accent**: `#18181B` / `#FAFAFA` - Minimalist single-color focus. No rainbow badge colors, no neon glows.

## 2. Layout & Typography Rules
- **No Clutter**: Remove decorative pills, excessive icons, glowing borders, and loud gradient badges.
- **Generous Whitespace**: Ample breathing room between sections, clear margins.
- **Minimal Data Table**:
  - Thin 1px border lines.
  - Subtle text headers.
  - Simple status dot (e.g., `● Ativo` in muted green `#22C55E`, or simple gray pill).
  - Subtle action buttons (`Ver`, `Editar`).
- **Sidebar Navigation**:
  - Clean monochrome sidebar with simple text links and subtle active background (`#27272A`).
  - No decorative rainbow tags or noisy badges.
